# Статистический анализ данных

Этот репозиторий содержит решения задач по статистическому анализу данных, включающие различные виды статистических проверок и построение доверительных интервалов для предоставленных выборок.

## Описательная статистика

### Характеристики выборки

Вычислены оценки:

- Объём выборки, минимум, максимум, размах.
- Среднее, выборочная дисперсия (смещённая и несмещённая оценки), стандартное отклонение.
- Асимметрия.
- Медиана.
- Интерквартильная широта.

### Гистограмма

Построена гистограмма (вероятностная) для выборочных данных. Использовано равномерное разбиение для гистограммы.

### Эмпирическая функция распределения

Построен график эмпирической функции распределения на основе выборочных данных.

## Проверка статистических гипотез

### Проверка гипотезы

- Определен вид критической области и вычислена критическая константа.
- Вычислена статистика и сделан вывод о принятии либо отклонении гипотезы.
- Вычислено p-значение.

## Проверка статистических гипотез о типе распределения

### Проверка гипотезы о типе распределения

- Построена гистограмма выборки с наложением графика функции плотности предполагаемого распределения.
- Определен вид критической области и вычислена критическая константа.
- Вычислена статистика и сделан вывод о принятии либо отклонении гипотезы.
- Вычислено p-значение.

## Построение доверительных интервалов

### Доверительные интервалы для параметров распределений

- Определен вид доверительного интервала в зависимости от задачи.
- Вычислены значения границ доверительного интервала.
